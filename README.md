# Koala releases

Release archives for Koala, which runs Linux VMs for development and CI on
Apple silicon Macs (macOS 26 or later). Koala is in **preview**: its
security proofs are not complete.

Download a release from the [Releases](https://github.com/kunalkushwaha/koala-releases/releases)
page, or install it with Homebrew:

```sh
brew install kunalkushwaha/koala/koala
koala system install
```

Each release's notes give the archive checksum and the runtime signing key.
