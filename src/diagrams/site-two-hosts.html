  1. Shared on both hosts: the koala CLI, the same /v1 API, the same VM specs, policy templates and security model, and a per-user manager that runs as you, with no root daemon.
  2. The stack splits by host: macOS on Apple silicon, macOS 26 or newer; Linux in preview on x86-64 Ubuntu 24.04, kernel 6.12 or newer, with /dev/kvm.
  3. Background manager: a launchd agent on macOS, a systemd user service on Linux. Hypervisor: Apple's Virtualization framework on macOS, KVM through Cloud Hypervisor on Linux.
  4. Sandboxes: App Sandbox for the helpers and a Seatbelt profile per VM run on macOS; Landlock and seccomp, and namespaces where Koala's AppArmor profile is loaded, on Linux. Secrets: the login Keychain on macOS; the desktop keyring (Secret Service) or encrypted files on Linux.
  5. Images: linux/arm64 on macOS, linux/amd64 on Linux. Install: Homebrew on macOS, a Debian package on Linux.
  6. On each host, every VM has its own kernel, disk and network. One code base: only the parts the host provides differ.
